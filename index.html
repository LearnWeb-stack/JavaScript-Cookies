Cookie Demo App

This demo illustrates how cookies work and how they differ from localStorage and sessionStorage. Try setting cookies with different expiration times and view them alongside other storage methods.

Cookies

  • Sent with every HTTP request
  • Max size: ~4KB total
  • Expiration: Can be set
  • Accessible from server-side
  • Can be secured and HTTP-only

localStorage

  • Never sent to server
  • Max size: ~5-10MB
  • Expiration: Never (persistent)
  • Client-side only
  • Available across browser tabs

sessionStorage

  • Never sent to server
  • Max size: ~5-10MB
  • Expiration: Tab close
  • Client-side only
  • Limited to current tab

Key Differences

Server Communication: Cookies are automatically sent with every HTTP request to the same domain. localStorage and sessionStorage are never transmitted to the server.

Expiration: Cookies can have explicit expiration dates. localStorage persists indefinitely. sessionStorage is cleared when you close the tab.

Storage Capacity: Cookies are limited to about 4KB total. localStorage and sessionStorage can typically store 5-10MB.

Accessibility: Cookies can be accessed both client-side and server-side. localStorage and sessionStorage are client-side only.

Security Options: Cookies have security options like HttpOnly, Secure, and SameSite flags. localStorage and sessionStorage do not.
